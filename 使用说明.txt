文枢文档转换器 1.1.0
====================

快速使用
--------
1. 双击 WenShuConverter.exe 启动程序。
2. 在左侧选择转换方向：Word 转 PDF，或 PDF 转 Word。
3. 把文件拖入窗口，或点击“选择文件”。
4. 选择保存位置（默认与原文件相同），点击“开始转换”。
5. 完成后点击右上角“打开输出文件夹”。

PDF 转 Word 的“转换方式”：
  - 可编辑文档（推荐）：按阅读顺序重排成普通段落、标题、表格，便于继续编辑。
  - 保留原始版面：尽量保持 PDF 的精确位置，可能出现较多文本框。

支持的格式
----------
Word 转 PDF：DOCX、DOC
PDF 转 Word：PDF（输出 DOCX）

说明
----
- 所有文件都在本机处理，不会上传到网络。
- Word 转 PDF 会优先使用本机 WPS/Word；没有时使用内置 LibreOffice。
- PDF 转 Word 默认可编辑模式会重排内容，不再精确保留原分页。
- 文档使用了本机未安装的字体时，请先安装该字体。
- 批量转换时按队列顺序处理；同名文件会自动编号，不覆盖已有文件。
- 转换使用独立的子进程，可以随时点击“取消转换”。
- PDF 转 Word 对扫描版 PDF 只能按页面图片还原，不做 OCR 文字识别。
- 加密 PDF 需要先解除密码保护。
- 复杂 PDF 的版面可能需要在 Word 中做少量调整。

常见问题
--------
如果双击后没有窗口：
  请确认使用发布文件夹中的 WenShuConverter.exe，且 engine 文件夹与它位于同一目录。
  错误日志位于：%LOCALAPPDATA%\WenShuConverter\logs\app.log

如果提示没有 Word 转换引擎：
  确认 engine 文件夹存在；也可以安装 LibreOffice，并在提示框中选择 soffice.exe。

如果 Windows 提示“已保护你的电脑”：
  点击“更多信息” → “仍要运行”。程序未做数字签名。

详细说明请阅读 README.md。
